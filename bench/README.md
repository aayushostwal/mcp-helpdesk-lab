# bench (coming in phase 3)

Reproducible benchmark of MCP tool designs, driven by headless Claude Code.

- `tasks/` task definitions and graders. `tasks/fixtures.json` (already generated by
  `helpdesk seed`) lists the ids and values the graders rely on.
- `harness/` runner, stream parser, grader and report builder.
- `results/` committed raw results, summary CSV and charts.
