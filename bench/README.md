# bench

Reproducible benchmark of MCP tool designs, driven by headless Claude Code. The methodology,
fairness rules and commands are in [docs/benchmark.md](../docs/benchmark.md).

- `tasks/` the 20 task definitions (`*.yaml`), their graders (`graders.py`), scripted oracles
  (`oracles.py`) and `fixtures.json` (generated by `helpdesk seed`).
- `harness/` runner, isolation, stream parser, matrix, report, fake `claude` for dry runs.
- `results/` committed results: `runs.jsonl`, `context_baseline.jsonl`, `raw/` (compressed,
  scrubbed streams), `summary.csv`, `summary.md`, `charts/`.
- `.cache/` (git-ignored) the pristine seeded database; `.runs/` scratch space.

```bash
uv run python -m bench list-tasks
uv run python -m bench check-tasks          # oracle and do-nothing checks, no model
uv run python -m bench run --matrix pilot --plan
uv run python -m bench run --matrix pilot --dry-run
uv run python -m bench report
```
